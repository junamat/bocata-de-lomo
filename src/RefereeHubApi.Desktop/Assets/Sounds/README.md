# Bundled sounds

Alert sounds, one file per sound id. The id saved in settings is the file name without `.ogg`.

| Id | Use |
| --- | --- |
| `ping` | info |
| `chime` | needs attention |
| `alarm` | act now |
| `error` | something failed |
| `confirm` | irreversible action done |

All five were made for this project, no samples or sound packs, they fall under the project's license.

User sounds don't go here: the app copies them into `Sounds/custom/` in the settings directory.
